ChartMind-VL：面向图表/报表截图的多模态问答模块

项目概览

ChartMind-VL 面向企业报表和数据看板解析场景，构建可接入 Agent 工作流的图表问答能力模块，支持截图上传、自然语言提问、模型对比、自动评估与 badcase 分析。

目前它是一个成长型项目：现阶段重点是把 prompt/demo 验证升级为可评估、可微调、可持续分析失败样本的多模态能力模块。

技术栈

  • Python
  • Qwen2.5-VL-7B-Instruct
  • Hugging Face Transformers
  • PEFT / QLoRA
  • Gradio
  • ChartQA
  • Prompt Engineering
  • 模型评估
  • badcase 分析

当前能力

项目将 notebook 流程拆分为多个可复用环节：

  • 数据适配
  • Prompt 构造
  • 模型推理
  • 自动评估
  • badcase 分析
  • Gradio Demo

这样做的目标是让图表问答不只是一个能跑的 demo，而是逐步变成可以评估、比较、复盘和接入 Agent 工具链的能力模块。

评估设计

项目计划或已设计 Base vs LoRA 的对照评估流程，关注三类指标：

  • EM
  • Token F1
  • Numeric Accuracy

图表问答里的难点通常不在“能不能回答”，而在数值读取、单位归一化、百分比理解、复杂计算和短答案格式稳定性。

Badcase 分析

badcase 分析会按结果变化归类：

  • improved
  • regressed
  • common failure

同时进一步记录失败类型：

  • 数值读取错误
  • 百分比归一化错误
  • 复杂计算错误
  • 图例或坐标轴理解错误
  • 输出格式不稳定

这些边界信息可以帮助 Agent 决定什么时候调用视觉理解工具，以及什么时候需要把结果交给更确定的代码或人工复核。

后续升级方向

下一步重点：

  • 吃透现有代码和实验流程
  • 补齐 Base vs LoRA 对照实验
  • 增加更清晰的评估报告
  • 将 badcase 分析做成可复用模块
  • 尝试作为 Agent 工作流中的视觉理解工具接入

这个项目会作为我从 AI 应用层走向多模态评估、微调和训练侧能力的过渡项目。
