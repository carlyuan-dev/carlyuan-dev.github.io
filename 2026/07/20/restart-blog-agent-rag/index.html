最近重新整理博客：先从 Agent 和 RAG 写起

最近把旧博客重新整理了一遍，准备把它当成一个长期记录技术学习和项目实践的地方。

短期内会先写 Agent 和 RAG 相关内容，因为最近接触的项目主要围绕 AI Tutor、工具调用、知识库检索、结构化输出和本地模型适配展开。这些东西如果只留在代码和零散聊天记录里，很快就会忘掉，还是需要写成文章慢慢梳理。

我希望每篇文章尽量回答一个具体问题，比如：

  • 一个 Agent 工具是怎么被声明和调用的？
  • RAG 里的 BM25 和向量检索分别在解决什么问题？
  • 为什么结构化输出不能只靠一句 prompt 保证？
  • 小语料知识库会遇到哪些检索边界问题？
  • 多模态图表问答应该怎么做评估和 badcase 分析？

目前会先从 Deeptutor-HKDSE 和 ChartMind-VL 两个项目开始写。前者更适合整理 Agent/RAG 系统，后者更适合整理多模态评估和微调实验。

后续大概会分成三类内容：

  1. 学习记录：概念、代码阅读、论文和文章摘记
  2. 项目实践：项目结构、模块设计、问题复盘
  3. 实验笔记：评估脚本、微调实验、部署尝试

先把能写清楚的东西写下来，后面再慢慢补图、补实验结果、补代码细节。
